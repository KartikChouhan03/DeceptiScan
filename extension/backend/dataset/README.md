# DeceptiScan Dataset Documentation & Provenance

This document establishes the origin, licensing, label-generation methodology, and data transformation pipeline for the datasets used in DeceptiScan.

---

## 1. Original Dataset Sources & Acquisition

The model training corpus was constructed from two primary open data sources:

### A. Kaggle Fake Reviews Dataset (Salminen et al., 2022)
* **File Name in Workspace**: `fake reviews dataset.csv`
* **Size**: ~15.3 MB (40,432 rows)
* **Academic Reference**: Salminen, J., Kandpal, C., Kamel, A. M., Jung, S. G., & Jansen, B. J. (2022). *Creating and detecting fake reviews on e-commerce platforms*. arXiv preprint arXiv:2205.10901.
* **Public Repository / Download URLs**:
  * Kaggle: [Fake Reviews Dataset (Kaggle)](https://www.kaggle.com/datasets/mexwell/fake-reviews-dataset)
  * Hugging Face / Alternative: [shamimreza/fake-reviews-dataset](https://www.kaggle.com/datasets/shamimreza/fake-reviews-dataset)
* **Schema**:
  * `category`: Product category (e.g. `Home_and_Kitchen_5`, `Books_5`, `Electronics_5`)
  * `rating`: Star rating (1.0 to 5.0)
  * `label`: Ground-truth label (`OR` = Original Review, `CG` = Computer-Generated Review)
  * `text_`: Review text body

### B. Cleaned Public Amazon Reviews Corpus
* **File Name in Workspace**: `public_reviews_dataset_cleaned.csv`
* **Size**: ~280 MB (381,734 rows)
* **Domain**: Real-world e-commerce product reviews crawled across Amazon product categories with seller/reviewer metadata.
* **Schema**:
  * `asin`: Amazon Standard Identification Number
  * `review_text`: User review body text
  * `reviewer_classified_fake`: Boolean flag assigned from user/seller behavioral clustering
  * `reviewer_labeled_fake`: Float label (1.0 = fake, 0.0 = honest)
  * `fake_review_product`: Boolean flag indicating whether the product was flagged in seller review manipulation campaigns
  * `review_is_removed_by_amazon`: Boolean/Float flag indicating whether Amazon subsequently suppressed or deleted the review

---

## 2. Label Generation & Mapping Methodology

To fine-tune a binary classifier ($0 = \text{Genuine}, 1 = \text{Fake}$), labels from the raw datasets were mapped as follows:

| Source Dataset | Source Column & Criteria | Output Label | Semantic Meaning |
|---|---|---|---|
| **Salminen et al.** | `label == 'CG'` (Computer Generated by GPT-2) | `1` | **Fake / Synthetic Review** |
| **Salminen et al.** | `label == 'OR'` (Original human review from Amazon) | `0` | **Genuine Human Review** |
| **Amazon Reviews** | `fake_review_product == True` OR `reviewer_classified_fake == True` OR `reviewer_labeled_fake == 1.0` OR `review_is_removed_by_amazon == 1.0` | `1` | **Manipulated / Fraudulent Review** |
| **Amazon Reviews** | Confirmed honest reviews (`reviewer_classified_honest == True` or `reviewer_labeled_honest == 1.0`) with NO fake indicators | `0` | **Genuine Organic Review** |

### Merged Corpus (`deceptiscan_training.csv`)
Merging both sources and performing cross-source deduplication produced **`deceptiscan_training.csv`**:
* **Total Records**: 72,877
* **Class 1 (Fake / Suspicious)**: 42,306 (58.05%)
* **Class 0 (Genuine / Organic)**: 30,571 (41.95%)

## 3. Train/Test Split Accounting: The 1,220 Record Resolution

An audit observed that $57,325 \text{ (Train)} + 14,332 \text{ (Test)} = 71,657$ records, leaving **1,220 records** unaccounted for relative to the 72,877 raw records.

The 1,220 records were **not accidentally lost**; they were removed during the strict text cleaning and quality filtration pipeline prior to model training.

### Step-by-Step Accounting

| Pipeline Stage | Records In | Dropped | Records Out | Reason / Rule |
|---|---|---|---|---|
| **Raw Merged Dataset** | 72,877 | - | 72,877 | Raw records in `deceptiscan_training.csv` |
| **Text Normalization** | 72,877 | 0 | 72,877 | Lowercase conversion, punctuation stripped (`[^a-z0-9\s]`), excess spaces collapsed |
| **Empty Text Filtration** | 72,877 | **14** | 72,863 | Reviews that contained only punctuation, whitespace, or invalid characters |
| **Post-Cleaning Deduplication**| 72,863 | **220** | 72,643 | Reviews whose text became identical once casing and punctuation variations were removed |
| **Length / Noise Filtration** | 72,643 | **986** | **71,657** | Extreme short noise (< 4 words, e.g. "thanks", "well made", single repeated letters) |
| **TOTAL FILTERED** | - | **1,220** | - | **Quality filtration delta ($72,877 - 1,220 = 71,657$)** |
| **Stratified Train Split (80%)** | 71,657 | - | **57,325** | Saved to [`train.csv`](file:///d:/Deceptiscan/DECEPTISCAN---BROWSER-EXTENSION-main/Deceptiscan/extension/backend/dataset/train.csv) (33,663 fake, 23,662 genuine) |
| **Stratified Test Split (20%)** | 71,657 | - | **14,332** | Saved to [`test.csv`](file:///d:/Deceptiscan/DECEPTISCAN---BROWSER-EXTENSION-main/Deceptiscan/extension/backend/dataset/test.csv) (8,416 fake, 5,916 genuine) |
